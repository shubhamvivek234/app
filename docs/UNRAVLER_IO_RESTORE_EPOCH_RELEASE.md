# Unravler.io v2.35 — stopped restore-epoch admission

Date: 2026-10-09. Local, uncommitted and undeployed. Foundations through v2.22 remain at `04ca28b5d1dd7bd213ea67e951970e19fd93bdf3`; earlier local work is preserved.

## Result and scope

The new opt-in controller installs an externally anchored workspace execution epoch while committing stopped authorities. Covered execution stays held for both a mismatched epoch and a correctly prepared epoch. `prepared=true` proves stopped admission; `activation_allowed=false` is mandatory. This release does not implement restored activation or grant new provider authority.

Defaults are `OUTREACH_RESTORE_FENCING_ENABLED=false` and empty `OUTREACH_EXECUTION_EPOCH`, mapped into the existing shared Compose environment and documented in the example environment. Positive legacy behavior requires a false flag, empty anchor and absent workspace root. A nonempty anchor denies even when the flag is false/malformed or a restored backup lacks the root. An installed root denies when configuration is removed. The operator must rotate a unique 64-character lowercase hex identity **outside the database and backup** before a restore; the system does not detect a restore automatically. Copying back both configuration and data can defeat this assumption.

## Stopped transaction and evidence

Private `outreach.core.restore_epoch.RestoreEpoch` inspects 19 collections, at most 100 rows each, returning bounded counts/blockers/digests without credential or recipient content. Preparation requires exact inspection and evidence digests, a bounded operator, all five execution/health flags exactly false, and an identified all-writer/cache drain assertion. Capacity, changed snapshots, unproven retained root shape and closed workspaces deny before stops.

The shared workspace guard and snapshot/majority transaction latch permissions, increment permission/campaign revisions, pause active/warming campaigns, stop armed health controls, disconnect active mailboxes, disable local webhook/integration sources and set `studio_review_required`. Voice consent, revoked status, original resources and credentials remain intact. Only recognized queued rows without retained ownership/submission/receipt or nested partial-stage evidence are cancelled. Accepted/possible/unknown/received work remains evidence; cancellation is not a provider revocation or delivery claim. Physical owners/tokens, provider budgets, resources and leases are retained.

Root and permanent metadata-only journal commit with the stops. UTC/native BSON millisecond normalization excludes read-fence counters. Exact historical retries return the saved result without repeating stops or touching replacements. A historical anchor cannot replace a newer root. Strict root/journal unique indexes follow evidence TTL removal; there is no standalone fallback or unknown-commit outer replay. Erasure recognizes the collection and retains minimal hashed provenance without reopening an existing closure.

`require(record=...)` can prove original-record metadata; it cannot synthesize a missing stamp. No worker stamps/relabels old work and no positive epoch activation path exists in this slice, including a fresh `grant(clear_latch=True)`.
